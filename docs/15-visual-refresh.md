# 视觉升级 · Clarity in every connection

2026-09-04 · 本轮保留品牌蓝 `#1677FF`、Logo 字形和品牌资产。继续使用 React、Tailwind、Radix 与 Lucide，不引入新的组件或字体依赖。

## 设计方向

清晰、可信、轻盈。白色与浅色背景承载信息，TP 蓝强调主要操作；连接状态同时使用文字与状态点表达。静态内容主要依靠留白和细边框区分，光晕仅用于连接状态等少量重点。

## 统一规则

| 维度 | 落地规则 |
| --- | --- |
| 拉丁字体 | 自托管 Inter Variable；数字使用 tabular-nums；保留现有字体族 |
| 中文 | 本地中文系统字体回退；标题 600、零字距、1.3 行高；正文 1.6 行高，不下载整套 CJK 字体 |
| 文档标题 | 随文章宽度在 32–48px 间调整；英文为辅助标签，同名不重复 |
| 正文与辅助 | 正文 16–17px；caption 从 12/18 升为 13/20；输入提示使用 slate-500 |
| 布局 | 320px 起适配；小于 1024px 使用导航抽屉；1024px 起 216px 侧栏；1280px 起 208px 右侧目录 |
| 阅读宽度 | 文章最多 832px；卡片列数与预览内边距依据文章宽度，而非屏幕宽度 |
| 间距 | 手机页面边距 16px；预览内边距 16/24/32px；标准组件继续使用现有 4px 间距体系 |
| 导航与控件 | 标题式导航；菜单、搜索与清除、关闭按钮为 44px；保留原有紧凑 sm 组件 API |
| 节点信息 | 名称、标签、延迟与负载可以换行；静态 NodeCard 不暗示可点击；有事件处理的卡片使用 button |
| 图标 | 单一 Lucide 功能图标体系；节点 Tab 使用 Server；Tab 常态 1.75、选中 2；品牌与国旗不按功能图标重绘 |
| 焦点与动效 | 键盘焦点使用实线轮廓；减少动态偏好下停止 CSS 位移过渡与循环动画 |

## Sitemap 与复用

首页 System Map 与顶部导航、侧栏、搜索共用 `app/routes.tsx`，避免维护第二份目录。保留品牌、基础、组件、模式、平台、下载、更新七组信息。

本轮优先升级 PageHeader、Section、Preview、Grid、DocTable 和布局组件，使全部文档页面共享改进。产品侧重点为 NodeCard、CountryListItem、SearchBar、TabBar、Button、Dialog、Sheet，以及连接交互演示。

## 范围边界

- Web 页面和组件已实现；Token 的 CSS、Tailwind、Dart、Swift、Kotlin、Android、Figma 导出随构建同步。
- 原生 App 与 Figma 文件本身没有被修改；原生端需另外应用中文排版规则和复核动态字体。
- 页面里的 VPN 连接为交互演示，不是实际隧道连接。
- 长表格、时间轴与精确像素标尺可局部横向滚动；不通过隐藏整页溢出来掩盖问题。
